## BetterBloat Ethernet Power Saving Fix v1.0.0

First public release.

### Included
- Safe detection of physical Ethernet adapters
- Driver-aware disabling of common Ethernet power-saving features
- Standardized EEE handling
- Windows/NDIS power-management changes
- PCIe Link State Power Management off on AC by default
- Automatic pre-change backup
- Restore utility
- Administrator `.bat` launchers
- Verification and clear `CHANGED / OK / SKIPPED / FAILED` output

### Normal installation
1. Download `BetterBloat-Ethernet-Power-Fix-v1.0.0.zip`.
2. Extract the ZIP.
3. Double-click `Run BetterBloat Ethernet Fix.bat`.
4. Approve the Administrator prompt.

Your Ethernet connection may briefly disconnect while the adapter restarts.
